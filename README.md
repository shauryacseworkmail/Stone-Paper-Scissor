# 🪨📄✂️ Stone Paper Scissors Game

A simple **Stone Paper Scissors** game built using **C++**, where the player competes against the computer.

## ✨ Features

* 🎮 Player vs Computer gameplay
* 🤖 Computer makes a random choice
* 🏆 Automatically determines the winner
* 🔄 Play multiple rounds
* 📊 Displays the game result clearly
* 💻 Simple and beginner-friendly C++ project

## 🎯 How to Play

1. Run the program.
2. Choose one option:

   * `1` → Stone 🪨
   * `2` → Paper 📄
   * `3` → Scissors ✂️
3. The computer randomly selects its choice.
4. The winner is decided according to the rules:

   * Stone beats Scissors
   * Scissors beats Paper
   * Paper beats Stone
5. Play again if you want another round.
